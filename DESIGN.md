# Design System — Aplikasi Daftar Kegiatan

Antarmuka menggunakan palet monokrom `#030303`, `#000000`, `#FFFFFF`, dan `#F3F3F3` dengan opasitas bayangan hitam. Dasar visual header, card, footer, tipografi, fokus, transisi, dan responsivitas mengikuti literal CSS halaman Profil Tugas 2.

## Token dan ukuran utama

- Font teks: `"SF Pro Rounded:Medium", ui-rounded, system-ui, sans-serif`, 16px / 24px, weight 500.
- Font heading/navigation: `"SF Pro Rounded:Bold", ui-rounded, system-ui, sans-serif`, weight 700.
- Header: min-height 56px, radius bawah 32px, lebar navigasi `min(1120px, calc(100% - 40px))`.
- Main: lebar `min(1120px, calc(100% - 40px))`, gap 48px.
- Card: radius 32px, padding 32px, bayangan bertingkat sama dengan Tugas 2.
- Footer: radius atas 32px, padding 16px 40px, ikon sosial 32px.
- Mobile: card radius 20px dengan padding 24px 20px; footer radius atas 24px dengan padding 24px 20px.

Status Terjadwal menggunakan badge ber-outline hitam dan status Selesai menggunakan badge hitam dengan teks putih. Tata letak kegiatan, form, filter, dokumentasi, dan navigasi menu mobile menyesuaikan kebutuhan aplikasi tanpa warna aksen tambahan.
