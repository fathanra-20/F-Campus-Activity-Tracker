# Tugas Pertemuan 7

## Materi: Component-Based UI Development with React

**Jenis Tugas:** Individu

**Teknologi:** React, Vite, JavaScript/TypeScript, CSS

### Deskripsi Tugas

Setiap mahasiswa diminta membuat **aplikasi web sederhana menggunakan React** dengan menerapkan konsep *Component-Based UI Development*.

Mahasiswa boleh memilih tema aplikasi, misalnya:

- Website profil mahasiswa.
- Dashboard tugas kuliah.
- Katalog produk.
- Website portofolio.
- Aplikasi daftar kegiatan.

**Aplikasi wajib dipublikasikan pada website pribadi masing-masing mahasiswa.**

### Ketentuan Tugas

**1. Menggunakan React**

- Membuat proyek menggunakan React dan Vite.
- Menggunakan JSX untuk membangun tampilan.
- Membuat minimal 5 komponen React yang dipisahkan ke dalam file berbeda.
- Menggunakan komponen yang dapat digunakan kembali (*reusable components*).

**2. Menerapkan Konsep React**

Aplikasi wajib menerapkan:

- **Components:** Memecah tampilan menjadi beberapa komponen.
- **Props:** Mengirim data dari parent ke child component.
- **State (**`useState`**):** Mengelola data yang dapat berubah.
- **Event Handling:** Menangani aksi pengguna, misalnya klik tombol atau input formulir.
- **Conditional Rendering:** Menampilkan konten berdasarkan kondisi.
- **List Rendering:** Menampilkan data array menggunakan `map()` dan `key`.

**3. Membuat Fitur Interaktif**

Minimal terdapat 3 fitur interaktif, misalnya:

- Menambahkan data.
- Menghapus data.
- Mencari atau memfilter data.
- Mengubah status data.
- Menampilkan atau menyembunyikan informasi.

**4. Tampilan Website**

- Tampilan rapi dan responsif.
- Memiliki navigasi yang jelas.
- Menampilkan nama dan NIM mahasiswa.
- Tidak terdapat error yang mengganggu penggunaan aplikasi.

**5. GitHub dan Publikasi**

- Source code diunggah ke repository GitHub.
- Minimal melakukan 5 commit.
- Aplikasi wajib berjalan secara online pada website pribadi.
- Website pribadi harus menyediakan link menuju aplikasi React.

### Pengumpulan Tugas

Mahasiswa wajib mengumpulkan:

1. **Link website pribadi** yang menampilkan aplikasi React.
2. **Link repository GitHub** berisi source code aplikasi.
3. **Screenshot tampilan aplikasi.**
4. **Penjelasan singkat** mengenai komponen React yang dibuat serta penggunaan props, state, dan event handling.
